# 车辆几何、材质与精度说明

本模型由本项目程序独立构造，参照明确标注为 2026 款 Neo 的公开实车照片，不是上汽大众原厂 CAD、扫描网格或制造级数字孪生。原照片只保存在 MATLAB 工程的 `references/exterior/`，不包含在网页、GLB 或公开 Git 仓库中。

## 重建依据与本次修正

优先核对汽车之家 Neo 图片 13402347（前45°）、13402344（侧面）、13402343（后45°）、13402346（前）、13402342（后），以及原有轮毂和金属车顶特写。尺寸依据现有核实参数：4836 × 1880 × 1505 mm，轴距 2766 mm；225/55 R17 的无载名义轮胎半径为 339.65 mm。

- 保持 +X 车头、+Y 左侧、+Z 向上；前后轴 X 为 1.476 / −1.290 m，未改动动力学参数。
- 以形状保持 Hermite 曲线控制车顶、机盖和后翼子板，增加机盖横向拱度、局部压筋以及前后保险杠的上下收拢。
- 保险杠采用与顶部、侧面共边的环形曲面。实渲发现大三角饰板会陷入弯曲表面，已在二维域先细分，再映射到弧面，修复黑色灯腔/格栅被白色车壳穿出的现象。
- 同材质几何合并，焊接近邻点；焊接后重新剔除退化三角形及未引用顶点，重新计算单位法线。
- B 柱按侧照归一化位置前移约 0.11 m；C 柱分隔带改为黑色；后固定三角窗收尖；取消独立凸出的白色轮眉片，以真实侧板圆弧切口表现轮眉。
- 保留 Neo 同色金属顶、五组黑银风车轮毂、半隐藏把手、分体前灯。加宽外侧日行灯和下部主灯，不主动点亮中央灯条与徽标。
- 五组银面采用宽扇面和倾斜表面，刹车盘及黑底压暗；橡胶 `metalness=0`、`roughness=0.96`，避免灰白金属胎面效果。
- 玻璃为深色反射表面，网页按场景设置 PBR 材质。动力部件由网页另建为教学示意，不包含在此车身资产中。

## GLB 契约与资源

根节点 `vehicle` 包含 `body` 与 `wheel_FL / wheel_FR / wheel_RL / wheel_RR`。车身按材质分组；四轮围绕本地 Y 轴转动，相同左右轮模板在前后轴复用。材质名包括 `paint`、`glass`、`rubber`、`alloy`、`drl`、`headlamp`、`taillamp`、`brakelamp`。

| 等级 | 车辆实例三角形 | GLB 字节 | 绘制图元数 | 唯一网格 |
| --- | ---: | ---: | ---: | ---: |
| 高清 high | 311102 | 6504120 | 39 | 27 |
| 标准 standard | 143801 | 3037456 | 39 | 27 |
| 低 low | 53521 | 1141840 | 34 | 24 |

以上为完整四轮车辆，不含网页地面、阴影额外绘制和教学部件；GPU 统计可能不同。GLB 没有外链纹理，不需要解码器网络请求。实际加载、FPS 和内存由浏览器性能报告给出；模型三角形数量不等于帧率承诺。详细字节、SHA256、边界和名义尺寸见 `public/models/manifest.json`。

生成时实测长 `4.8359999657 m`、漆面宽 `1.8799999952 m`、从胎底至顶高 `1.5050000003 m`；浮点误差小于 `10⁻⁵ m`。宽度排除外后视镜；全包络含镜宽约 `2.254 m`，这个镜宽是照片近似值，并非已核实官方参数。外观尺寸包含徽标等最外端几何，不将局部照片推断写入科学模型。

## 实拍比对与剩余差异

本地 `figures/web_geometry/` 保存 1920 × 1080 WebGL 六视图，以及 `compare_front45.png / compare_side.png / compare_rear45.png / compare_front.png / compare_rear.png` 五张 3200 × 1400 对照图。源照片完整保留水印。两侧观察方向接近，但没有相机内参、透视矫正或标定板，因此不能将像素差称为毫米级实车误差。

侧图只做人工近似诊断：将 `neo_13402344.jpg` 等比缩放到 1600 × 1200，读前后轮心横坐标约 414 / 1180 px；WebGL 侧图 1920 × 1080 对应约 554 / 1316 px。使用各自轴距像素归一化 `(特征横坐标−前轮心)/(后轮心−前轮心)`，避免把不同图片缩放量混同。人工读点约 ±10 px，图像的轻微透视仍影响数值。

| 特征 | 实拍归一化位置 | WebGL 归一化位置 | 差值（轴距比例） |
| --- | ---: | ---: | ---: |
| 前窗下沿前端 | 0.178 | 0.189 | +0.011 |
| B柱下沿中线 | 0.590 | 0.591 | +0.001 |
| 车顶最高区中心 | 0.614 | 0.596 | −0.018 |
| 后三角窗最末端 | 1.081 | 1.129 | +0.048 |
| 前保险杠侧轮廓最前点 | −0.321 | −0.293 | +0.028 |
| 后保险杠侧轮廓末端 | 1.376 | 1.370 | −0.006 |

这些点证实主要舱体和轴距比例接近，但同时揭示后侧三角窗末端偏后、前保险杠侧面仍偏短/直。它们不是整体“相似度百分比”，也不是经过标定的误差统计。

仍可见的差异：车门大面比实车平直，腰线和后翼子板体积不足；前灯腔层次、灯带端部与保险杠细部仍简化；C 柱/后侧三角窗转折未达到实车曲率；轮毂五组银面已接近对应风格，但精细切面和黑银比例仍近似；后保险杠黑包围和尾灯折线不等同原厂结构。未建立真实内饰，玻璃暗部是视觉遮挡层。不能据此声称达到车厂配置器或原厂扫描网格的外观精度。

## 复现与检查

在 web 目录执行 `npm run export:models` 重新生成三个 GLB；执行 `node --test tests/models.test.mjs` 检查真实二进制中的索引、有限位置、单位法线、退化三角形、未引用顶点、轴位、材质与节点契约、文件哈希和 LOD 层级。

可选本地检查：安装 Microsoft Edge 后执行 `node scripts/render-model-review.mjs`，通过实际 Three.js / Edge WebGL 输出六视图，浏览器与临时 HTTP 服务在脚本退出时关闭。运行 `powershell -File scripts/create-local-comparisons.ps1` 需有父工程的参考照片，仅生成本地对照图。不要将这些含照片的图复制到 `public/`。

该资产由多个开放表面/零件组成，不是封闭实体。不以有限单位法线测试冒充完整 CAD 自相交、流形或制造公差检验；视觉交界仍应结合本地多角度渲染验收。
