# WebGL 性能实测

测量日期：2026-11-05。原始观测见 [performance.json](performance.json)，脚本为 `scripts/benchmark-browser.mjs`。使用 Vite **生产构建**的 localhost 预览，Edge 156.0.4314.58 headless，WebGL 实际由 NVIDIA RTX 5060 Laptop GPU / ANGLE D3D11 渲染，没有禁用 GPU或启用软件渲染。

硬件：AMD Ryzen 9 8945HX、32 逻辑处理器、31.80 GiB RAM、RTX 5060 Laptop 8151 MiB、驱动 582.05。渲染主动限制到约 60 FPS。这里的 FPS 是实际提交渲染帧的调度间隔，包含 UI 开销，**不是独立的 GPU shader 计时**。

| 场景 | 浏览器视口 / 绘图缓冲 | 渲染 FPS 中位数 | P95 帧间隔 | 浏览器 CPU 单核等效 | 整卡 GPU 瞬时抽样 |
|---|---|---:|---:|---:|---:|
| 标准 LOD1 + 自动旋转 | 1440×1000 / 1264×420，DPR1 | 59.88 | 16.8 ms | 27.09% | 10% |
| 高清 LOD0 + 自动旋转 | 同上 | 59.88 | 16.8 ms | 26.80% | 2% |
| 轻量 LOD2 + 自动旋转 | 同上 | 59.88 | 16.8 ms | 27.23% | 12% |
| 手机视口仿真 + 轻量自动 | 390×844 / 534×525，实际DPR1.5 | 59.88 | 16.8 ms | 28.42% | 8% |

每个单场景在预热后观察 8–10 秒。CPU 由 CDP 读取本测试浏览器进程树累计 CPU 时间差，100% 表示一个逻辑核心占满；全机归一化值需再除以32。GPU 利用率、显存和功耗来自 `nvidia-smi` 整卡抽样，包括桌面及其它程序，不能据此声称网页专属 GPU 占用。高清 CPU 少于标准属于短时间测量波动，不能推断高清更省资源。

首次导航到模型可用为 **1125.2 ms**。标准 GLB 的本机网络资源时间 17.7 ms，加载器解析完成 68.2 ms；高清/轻量在已有页面切换时分别44.0/19.8 ms，属于不同缓存、加载条件，不能当成公网首访时间。公网加载需结合实际网络另测。

## 持续回放

长途工况、标准LOD、透明车身、20×回放：预热后持续观察 **120.81 秒**、13次采样，仿真采样时间从80推进至2496秒。

- 各观测 FPS 中位数均约59.88，P95约16.8ms。
- Three.js 几何70、纹理4、程序8，13次观测均不变。
- JS堆从22,762,105到22,999,312字节；采样峰值25,784,554字节，结束强制GC后22,248,330字节。
- 浏览器CPU单核等效55.65%，约全机1.74%。整卡GPU抽样0–16%，显存2211–2268MiB，包括其它程序占用。

没有观察到持续增长的 Three.js 资源或回收后堆内存。这是两分钟的有限观察，**不证明任意时长、任意浏览器都没有内存泄漏**。

## 边界与优化

模型/数据按需加载；最多缓存四组数据；同材质合并和四轮共享网格；LOD切换主动释放旧资源；绘图分桶保留极值，完整JSON不降采样；非活动页面暂停提交帧；移动默认轻量，低帧率自动降档；高DPR限制到1.5，必要时降到1。

本次达到本机约60FPS的目标，但没有第二台普通笔记本或真实手机的性能数据。触控仿真使用同一RTX5060，不能用来承诺手机60FPS。MATLAB和网页的实际绘图分辨率、测试回放条件不同，不据此宣传精确倍数的跨平台加速。
