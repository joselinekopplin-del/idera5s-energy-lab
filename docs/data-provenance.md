# MATLAB 数据管线与数据边界

网页只回放已保存的 MATLAB 数据，不包含在线 MATLAB 求解器，也不会因为切换颜色、视角、工况或策略而重新计算物理结果。

## 导出与更新

在 `web/` 中执行：

```sh
node scripts/export-data.mjs
node --test tests/data.test.mjs
```

默认读取 `web/` 上一级 MATLAB 项目中的 `results/`。独立网站仓库不包含 MATLAB 工程；更新时显式指定本机原始项目目录：

```sh
node scripts/export-data.mjs --source "<MATLAB 项目根目录>"
```

此命令只读取 64 组正式 CSV、对应 MAT、汇总 CSV 和来源代码；只写入网站 `public/data/`。不会运行 MATLAB，不会覆盖科研结果。执行前建议保留原工程哈希基线。导出器要求 16 × 4 完整矩阵及现有 3 组不可行结果；若科研数据集发生了有意的版本更新，需要先审查这些断言再重新发布。

## 数据格式

- `public/data/catalog.json`：64 个轻量结果描述，含中文标签、逐项汇总、可行性、时间范围、文件大小、结果 JSON 的 SHA-256。
- `public/data/<scenario>_<strategy>.json`：一个完整工况策略结果。`fields` 保持原始 CSV 的 41 列顺序；`rows` 保留每一行、每个双精度数值。每组单独加载。
- `version` 是原始 64 组 CSV/MAT、汇总 CSV 和科学计算源码摘要共同构成的内容版本号；同一输入会产生相同版本。
- `source.csv` / `source.mat` 是来源的项目相对路径，只用于追溯，并不是公开下载链接。MAT 文件记录 SHA-256；数值来自其配套已保存 CSV，未重新求解。
- `source.sha256` / `source.matSha256` 是原文件摘要；目录中另有导出后 JSON 的摘要。HTTPS 浏览器加载结果时使用 Web Crypto 验证 JSON 摘要，防止目录与数据来自不同版本。
- 无舍入、平滑、插值、降采样或人为调色数值。CSV 中有限数字转换为 JavaScript IEEE-754 double；`NaN`、`Inf` 使用 `null`，不能当成零。逐字段缺失数记录在 `nonFiniteByField`。
- 最后一个样本时刻为 `endTime_s`，工况积分时长为 `duration_s`。例如 1200 个 1 秒采样，时刻从 0 到 1199 秒，总时长为 1200 秒。

客户端采用最多 4 组结果的 LRU 缓存，目录加载时不下载全部 64 组。切换工况时只请求所需结果；策略比较最多请求同一工况的 4 组。最长工况有 14400 个样本，JSON 约 7 MB，网络较慢时需显示加载状态并允许取消过期请求。

## 科学含义

`Speed_mps` 是规定的**参考速度**，`Distance_km` 是该速度积分得到的**参考累计里程**。本项目使用逆向准静态能量模型，未求解动力不足时实际达到的车速。车轮动画也只对应参考里程。

`Feasible` 直接复制正式 `scenario_summary.csv`，不在网页重新分类。当前不可行的三组是：

| 工况 | 策略 | 未满足驱动能量 kWh | 需求满足比例 |
|---|---|---:|---:|
| 冬季 −10°C | 纯电优先 | 0.000156236678947432 | 0.999854150780934 |
| 冬季 −10°C | 规则控制 | 0.0016558860565898 | 0.998454206209178 |
| 冬季 −10°C | 电量保持 | 0.0016558860565898 | 0.998454206209178 |

MATLAB 原汇总可行性阈值为 `Unmet_kWh < 1e-4 && AuxUnmet_kWh < 1e-4`。网页必须显著保留不可行标记，不能把参考轨迹称为已达车速。

功率约定：

- `Motor_W > 0` 驱动，`Motor_W < 0` 发电；电机电功率可由 `Motor_W + MotorLoss_W` 读取原模型的机械功率与损耗关系。
- `Battery_W > 0` 放电，`Battery_W < 0` 充电；辅助负载会使电机发电功率与电池净充电功率不同。
- `Regen_W` 为正的制动回收直流功率，尚未扣除辅助负载。`Regen_kWh` 是其积分。
- `BatteryNet_kWh` 为 `Chemical_W` 的积分，属于电池化学能净消耗，不能替换成电池端口电功率积分。
- `EngineStarts` 每行是当前步的启动事件，累计次数需要求和；汇总中的同名列已经累计。
- `EngineRPM > 0` 表示保存的模型发动机处于运行状态。不能仅用 `ModeCode` 判断发动机开关，因为停车状态的模式编码为 0。
- `Fuel_W` 是燃油化学功率；`FuelUsed_L` 是累计燃油量。即时燃油体积流量若未明确使用原参数换算，应显示已有化学功率而不编造 L/h。
- `Battery_C`、`Motor_C`、效率和转速是模型计算值，不是实车遥测。停车时效率字段可能仍存储通用效率映射数值，不能解读为停车状态的实测效率。

运行模式编码依次为停车/辅助负载、纯电驱动、混合驱动/发动机运行、制动回收、发动机驱动并充电。

所有工况是自定义合成工况，**不是 CLTC/WLTC 认证工况**。策略比较应同时查看燃油、净耗电和最终 SOC；`EqualizedFuelDiagnostic_L` 仅是原工程采用通用发电效率的诊断量，不是官方综合油耗。初末 SOC 未匹配的结果不能仅按燃油量宣传策略优劣。

## 验证与发布边界

`tests/data.test.mjs` 在公开仓库中验证 64 组 JSON 摘要、时间轴、无降采样、缺失值、回收符号及汇总一致性；在本机原工程旁运行时，还逐单元核对所有 CSV 数值，重新验证 64 个 CSV、64 个 MAT 和科学计算源码摘要。独立仓库的源码核验测试会明确跳过，因为 MATLAB 原工程不随网站公开。

公开目录只包含派生的数值数据、相对来源名和摘要，不包含 MATLAB 临时文件、账号凭据、API Key、原始汽车照片或商业 CAD。

本次实际导出版本为 `matlab-csv-98d5b83d4fe79b96`，共 130560 个采样、41 个原字段，即 5352960 个数值单元。64 个结果 JSON 合计 62167422 字节，目录 107724 字节；最大文件为 `longTrip_SOCHold.json`，7665579 字节。2026-11-05 在原 MATLAB 工程旁运行 `node --test tests/data.test.mjs`，5 项全部通过，无跳过；包含全部单元精确相等验证与 128 个正式 CSV/MAT 哈希复核。公开仓库 CI 的本地原文件比对项按设计跳过，其余测试仍会执行。
