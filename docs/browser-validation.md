# 浏览器功能验收

2026-11-05 在 Windows 本机以 Microsoft Edge headless 运行 `pnpm test:browser`。最终结果 **12 通过、0 失败、1 跳过**，耗时 30.6 秒。跳过项为明确独立运行的 120 秒长回放性能测试，不计入本功能通过数。机器可读结果见 [browser-validation.json](browser-validation.json)。

桌面视口 1440 × 1000，DPR 1；移动仿真视口 390 × 844，触控开启、DPR 1。WebGL 实际渲染器为 NVIDIA GeForce RTX 5060 Laptop GPU / ANGLE Direct3D 11。测试浏览器没有禁用 GPU。

| 检查 | 实际验证方式 | 结果 |
|---|---|---|
| GLB 与按需数据 | 渲染三角面与绘制调用大于零；首屏只请求一个结果 JSON | 通过 |
| 鼠标轨道、滚轮、自动停止、复位 | 真实鼠标输入，读取相机位置变化与距离；复位到前45° | 通过 |
| 五色、五灯、摄影棚、六视角 | 点击/选择控件，读取材质颜色、灯腔发光强度与相机变化 | 通过 |
| 主题、键盘、帮助弹窗 | 浅/深/跟随系统、刷新保留、方向键和对话框操作 | 通过 |
| 透明/隐藏/拆解与射线点选 | 实际点击电池投影位置，确认电池数据弹窗；检查部件位移 | 通过 |
| 回放与图表同步 | 播放时间推进、车轮转动、点击图表后四游标一致 | 通过 |
| 制动回收方向 | 选择制动工况，在负功率时检查箭头实际坐标确实反向 | 通过 |
| 三组不可行结果 | 逐个选择冬季 −10°C 的前三策略，确认动力缺口；ECMS仍可行 | 通过 |
| 策略比较 | 同工况四组结果、六种曲线、启动次数/末端SOC、选回放 | 通过 |
| 刷新与资源路径 | 四条hash路由刷新、页面无异常、所请求资源无HTTP错误 | 通过 |
| 三档LOD稳定性 | 高清→轻量→标准循环两次，几何/纹理数没有逐轮增长 | 通过 |
| 移动交互与减少动态效果 | CDP真实单指/双指事件、手机宽度无溢出、触控播放、禁用自动旋转 | 通过 |

测试曾发现并修复：隐藏标签导致播放速度没有可访问名称、LineSegments 的射线阈值使相邻部件被误点选、复位按钮在相同预设下未还原相机。终轮对这些行为重新进行了真实输入验证。

三档LOD切换结束时，标准档两次均为 55 个几何资源、4 个纹理资源和6个着色程序。此计数是 Three.js 资源对象数，不是显存字节。功能检查的即时帧率不用于声明长期性能，独立性能报告应记录持续采样和负载。

本报告验证的是本机开发服务。线上 HTTPS 发布、网络加载耗时、真实手机/普通笔记本帧率、外观与实车的人工视觉相似度不由这些自动化测试证明，需结合相应独立验收证据。
